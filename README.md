# 🌹 carnation-card · 스승의 날 응원 카드 메이커

제자가 선생님께 마음을 전하는 **스승의 날 응원 메시지 카드**를 1분 안에 만들어 PNG로 받을 수 있는 웹 도구입니다. 글쓰기를 어려워하는 학생도 **🎲 추천받기** 버튼 한 번이면 바로 시작할 수 있어요.

> made with ♥ by **룰루랄라 한기쌤** ([@coolhanman](https://www.youtube.com/@coolhanman))

## ✨ 기능

### 디자인
- **4가지 디자인 테마**
  - 🌹 카네이션 클래식 — 정중하고 전통적인 톤
  - 📝 손편지 노트 — 빈티지 노트 종이, 손글씨 감성
  - 🌸 파스텔 봄 — 부드럽고 귀여운 톤
  - ✨ 별빛 감사 — 네이비 + 골드, 차분하고 깊은 감사
- **6가지 한글 손글씨 폰트** — 개구 / 손편지 / 멜로디 / 싱글데이 / 동해 / 큐트
- **데코 토글** — 카네이션 · 별 · 하트

### 메시지 추천 시스템 (v1.1) 🎲
- **120개 메시지 풀** — 학년군 3단계(저/중/고) × 카테고리 5종 × 8개
  - 저학년(1·2): 짧고 단순, 감정 직접적
  - 중학년(3·4): 적당한 길이, 구체적 경험
  - 고학년(5·6): 깊이 있는 표현, 성찰
  - 카테고리: 감사 · 존경 · 추억 · 응원 · 사랑
- **🎲 추천받기 버튼** — 한 번에 한 문장씩, 부담 없이
- **🔁 다른 문장** — 마음에 안 들면 즉시 다음 문장으로
- **♻️ 직전 5개 제외 메모리** — 같은 문장이 연달아 나오지 않음
- **📚 전체 목록 보기** — 카테고리별 문장 비교하며 고르기
- **🔄 자리표시자 자동 치환** — `{선생님}`이 받는 분 이름으로 자동 변환
- **✏️ 살짝 다듬기 힌트** — "한 단어만 바꿔봐도 좋아요" 가벼운 안내

### 출력
- **PNG 다운로드** — 1080×1350 (인스타그램 + 인쇄 친화 사이즈)
- **인쇄** — 학급에서 단체로 출력 가능
- **모바일 우선 반응형** — 폰에서도 편하게 만들기

### 인프라
- 단일 HTML, 외부 의존성 최소 (Google Fonts + html2canvas)
- 빌드 단계 없음 — GitHub Pages에 그대로 배포

## 🚀 사용 방법

1. [라이브 데모](https://plusiam.github.io/carnation-card/)에 접속
2. 디자인 테마 선택
3. 받는 분 / 내 이름 / 학교·학년반(선택) 입력
4. **메시지 작성** — 직접 쓰거나, 학년·종류 선택 후 🎲 추천받기
5. 글씨체와 데코 선택
6. **PNG로 다운로드** 버튼으로 저장
7. 카톡, 이메일, 인쇄 등 자유롭게 공유

## 🛠 기술 스택

- Vanilla HTML / CSS / JS — 빌드 단계 없음
- [html2canvas](https://html2canvas.hertzen.com/) — PNG 캡처 (CDN)
- [Google Fonts](https://fonts.google.com/) — 한글 손글씨 폰트 다수
- 단일 파일(`index.html`)로 GitHub Pages 정적 배포

## 🌐 GitHub Pages 배포

2. Repository → **Settings → Pages**
3. Source: `Deploy from a branch` → Branch: `main` / `(root)` 선택 후 Save

## 📝 메시지 풀 커스터마이징

메시지를 학급/학교 톤에 맞게 수정하시려면 `index.html`의 `messagePool` 객체를 수정하세요. 자리표시자 `{선생님}`을 사용하면 받는 분 입력값으로 자동 치환됩니다.

```javascript
const messagePool = {
  '저학년': {
    '감사': [
      '선생님 정말 고마워요!',
      '{선생님} 만나서 행복해요.', // ← {선생님}이 받는 분 이름으로 자동 치환
      // ... 8개
    ],
    // ... 5개 카테고리
  },
  // ... 3개 학년군
};
```
